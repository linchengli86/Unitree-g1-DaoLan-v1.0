# 一键复现契约：经验资产到可交付产品

## 用户目标

资产不只是源码归档，而是把 SLAM、定位、导航、控制和导览编排经验封装成固定流程。兼容的 G1/PC2 环境下，用户只负责遥控建图、创建展点及物理安全确认；不需要在终端调 ROS、TF、话题、加速度或模型接口。

人工必须保留：硬件通电、换电、官方运动模式、落地/拆绳、地图现场核对、展板内容审核和紧急监护。这不是技术排错，不能自动跳过。

## 固定网页路径

```text
首次：启动 → 环境自检 → 开始建图 → 遥控走场地 → 结束并验收地图
                                      → 初始化/定位 → 登记展点 → 选点导览
再次：启动 → 初始化/核对当前位置 → 选点导览
```

Quickstart 只描述这一条用户路径；API、参数和历史故障移到开发文档。模型、麦克风和讲解都是可选模块，不能阻塞纯运动。

## 当前已具备

- 软件网站启动、分阶段初始化、人工粗先验重定位与核验。
- 点位/展板登记、实时地图、选点移动、白名单调度、停止与到达检查。
- 建图与二维保存脚本、三维/地面地图与关键位姿输出。
- 软件回归和实际单点移动证据；源码 Git 快照与私有资产分离。

## 尚未实现的一键复现条件

1. **环境准备**：固定支持的系统/架构/SDK，锁定并记录依赖；自动检查/构建及可恢复安装。不把运行日志中的成功当作新 PC2 安装验收。
2. **网页建图生命周期**：缺地图时能进入建图而非初始化失败；禁用自动运动，与导航/重定位互斥；只管理归属明确的节点，断连/取消可恢复。
3. **地图提交**：在隔离会话输出三维地图、地面地图、关键位姿和二维栅格；核验非空、坐标/元数据一致、哈希及人工预览；备份旧图，原子激活新版本，点位绑定地图版本。不得直接覆盖已验证现场图。
4. **就绪收敛**：依次核验传感器、TF 时效、定位、规划和平滑/控制链路，自动等待/恢复有界；失败展示一个清楚的用户动作，不要求复制十条排错命令，也不放宽安全阈值。
5. **权限向导**：安全设置 PIN、独立导航门和可选 Omni；保留手臂默认关闭；纯运动启动不因无语音模块失败。
6. **干净安装验收**：用新的兼容 PC2/干净部署与新地图，完整走完网页流程；保留真实安装、场地和故障恢复结果，才能发布为一键复现版本。

## 验收标准

- 一个有版本号的启动入口和不超过一页的用户 Quickstart。
- 用户从网站完成建图、地图激活、重定位、点位创建与移动，无终端 ROS 调试。
- 新场地没有预装地图/点位也可开始；原场地不会被自动覆盖。
- 无模型 Key/麦克风仍能移动；讲解故障不破坏导航。
- 不靠增加 TF 容差、改时间戳或绕过路径核验来宣称成功。
- 安装/任务失败可重复进入同一向导，无重复节点、无人值守自动使能或重启续跑。

此文档是产品验收契约，不是宣称上述待办已经实现。当前版本应称“已验证能力的源码与演示基线”，而不是正式零调试全流程发行版。
