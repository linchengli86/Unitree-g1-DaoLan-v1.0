# 一键复现契约：经验资产到可交付产品

## 用户路径

目标：兼容 G1/PC2 上，用户只负责遥控建图、登记展点和物理安全确认；不应要求用户逐条调 ROS/TF/话题。

```text
首次：quickstart --prepare → /setup → 遥控建图 → 保存/审核/激活
                                     → 初始化/定位 → 登记展点 → 选点导航
再次：quickstart → 初始化/核对当前位置 → 选点导航
```

人工必须保留硬件通电、换电、官方运动模式、落地/拆绳、地图现场核对、内容审核和紧急监护。Omni、语音、麦克风是可选模块，不能阻塞纯运动。

## 本候选版已实现的源码

- `quickstart.sh`：支持平台检查、显式准备依赖、SDK/ROS 构建、版本记录、重复启动入口。
- `/setup`：缺地图可先进入建图；与初始化/任务/重定位互斥，仅遥控，不发送速度或使能运动。
- 隔离会话输出五项地图资产；二维图检查 frame/时间/栅格，PCD/关键位姿结构与哈希检查，人工预览审核。
- 原导航/控制服务只在归属和空闲核验后退出；仅本次建图进程组收到退出信号。保存未退出时保持占用，不强杀。
- 离线备份后逐文件替换，失败回滚，版本记录最后写入。不是跨文件系统的原子事务，也不保证断电中途自动恢复。
- 新图归档旧点位登记，保留照片/文献；需重新登记新坐标系点位，旧图可从精确备份恢复。
- PIN/导航权限向导；手臂门默认关闭，设置权限不使能运动。新配置默认关闭音频，不要求模型 Key。
- 网站重启识别仍持会话锁的建图 worker，阻止新任务；不续跑导航或激活未审核产物。

此前已验证：原现场旧地图、独立扫描重定位、动态障碍响应、单点自主移动和到达核验；这些不自动构成新增网页建图的验收。

## 正式发布前仍须验收

1. 新 PC2 安装：Ubuntu 20.04 aarch64、可信 Noetic 源和厂商网络前提下，从空项目实际运行准备命令；验证 Livox、CycloneDDS、Unitree SDK 及本次 C++ 改动编译。
2. 新地图：从无地图启动网页，走完整场地、结束保存，核对 3D/地面/二维图坐标及几何一致性，再定位、登记点、导航到达。不把结构校验或预览等同 SLAM 精度验收。
3. 故障恢复：取消、网页重启、网络断连、慢保存和安装失败的真实状态；断电中途切图需人工确认资产完整性，不自动猜测版本。
4. 路线安全：逐路线真实网页移动、持续负载下 TF、停止与监护。不增加 TF 容差或绕过路径核验来掩盖故障。
5. 环境发行：apt 依赖记录而非全量镜像锁定；上游来源/许可和新硬件兼容持续审查。ROS 源签名问题明确报错，不关闭验证。

本候选版可以复现源码与隔离测试，尚不能保证新硬件/新场地无需额外调试。正式发布需要保存上述真实验收证据。[验证记录](VALIDATION.md)
