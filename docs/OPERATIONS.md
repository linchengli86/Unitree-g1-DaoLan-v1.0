# 现场操作手册

## 网页首次设置补充（候选版）

新用户按 [Quickstart](QUICKSTART.md) 操作 `/setup`。建图只遥控，独立保存后人工预览再激活；旧图、标注和点位登记归档，照片/文献保留。切图后重新初始化/定位并登记新图点位。保存/取消退出前不要换电；边界见 [WEB_ONBOARDING](WEB_ONBOARDING.md)。下文为原现场参考。

## 换电与启动

换电前取消任务、禁用运动，观察机器人已停稳；物理支撑、官方模式切换与断电按设备正式操作流程执行，不能依靠网页代替。停止后若需关闭 PC2，在 SSH 中运行 `sudo shutdown -h now`，确认关机完成再处理电池。不要在运动中或悬空状态执行导航。

换电后连接 SSH，检查 IP；网页版“一键初始化”逐项检查资产、内部网络、安全控制器、ROS 导航、传感器和定位。软件无法给雷达硬件通电，也不能自动确认双脚落地。机器人处于零力矩、悬空或吊绳承重时保持运动禁用；需要导航时由真人切官方运动模式、落地并拆绳，现场持遥控器监护。

## 初值、重定位与点位采集

未知位置时地图点选当前**大致位置与朝向**，不是要求厘米级准确。当前有界匹配使用 1 m、±45° 搜索，独立扫描核验后显示绿色结果；真人对照墙体、障碍与朝向确认。相对粗先验的修正量不是定位精度。`/slam_reloc_check=True` 单独不足以证明配准正确。

“添加导览点”的读取定位，是在已有有效定位下采集当前停稳位姿；不能在未定位环境凭空知道绝对坐标。机器人不动但提示移动/过期时应诊断定位/TF，而不是不断重录。

记录点位流程：人工带到展点 → 调整朝向 → 停稳 → 上传展板并整理 → 核对草稿/照片 → 读取稳定位置 → 保存。现有 8 个点位和 7 张展板属于现场私有数据，不随源码包发布。

## 网站仅移动

打开 `/navigation`，选登记点，勾选落地/运动模式/拆绳/停稳/监护，点击准备，核对目标后 PIN 确认。也可从点位卡片“前往此点（仅移动）”进入；进入页面或准备本身不运动。

任务只执行 `navigate_to_point`：核对地图、实时定位、TF、scan、本目标有效路径，满足条件后才使能；保持实时检查；到达或失败后禁用，核验位置 ≤.20 m、朝向 ≤.20 rad。当前上限 .60 m/s 和 .70 rad/s，避障/转向/终点会减速，不是恒速保证。

其他点位第一次走行须逐条现场验收。失败读任务日志；不要重复点击期待绕过安全检查。页面显示“提交”不表示“到达”；需最终状态和到达指标。

## 讲解与示教路线

讲解是独立模块：`/assistant` 问答/TTS，`/agent` 基于本点先验动态构思并组织导航/讲解。展板整理后的旧稿是先验，不是要求每次逐字朗读。文献通过 `/knowledge` 绑定和审核；不要默认未经核对的生成内容可信。

示教路线录制/回放保留兼容，见 `tool/scripts/record_teaching_path.py`、`play_teaching_path.py` 与 `scripts/replay_teaching_route_safe.py`。新点位移动由规划器实时规划，不要求先录路线。

## 建图（会写现场数据）

新建图前备份现有二维地图、PCD、地面 PCD、关键位姿、点位及路线，并记录哈希；停止导航，禁止模型自动启动建图。`bash scripts/mapping.sh` 启动独立建图会话，人工安全走完整个区域。PCD 保存行为以 `mapping.yaml` 和节点退出日志为准；不能因为 Ctrl+C 就认定所有文件已经保存。

`bash scripts/save_map.sh` 保存 `/projected_map` 二维栅格到 `map/map.*`，**不是三维 PCD 保存命令**。停止前后检查消息、文件大小、时间与日志，地图一致性核验后再替换导航基线。旧地图恢复需整套一致（PCD、地面、关键位姿、二维及相关 JSON），不能混搭不同轮次。

## 停止

网页“停止全部任务”或 `bash scripts/guide_stop_motion.sh` 请求取消/急停/禁用，查看返回停止确认。定位或指令失效时控制器看门狗请求停止，但软件停止不是物理安全保证；紧急情况使用官方遥控器/设备急停。不要杀不明 PID 或全部 ROS 进程代替归属检查。
