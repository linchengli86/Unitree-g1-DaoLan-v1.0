# Quickstart · 从启动到网页导览

目标：首次进入新场地只需要遥控建图、登记导览点；同场地重启只需初始化、核对定位、选点前往。命令行和 API 细节留给开发者，不作为用户主流程。

## 1. 启动网站

在操作电脑执行（PC2 已完成环境部署，地址按现场调整）：

```bash
ssh unitree@192.168.3.64 \
  'cd ~/robot/DaoLan && bash scripts/mobile_guide_start.sh'
```

浏览器打开 **http://192.168.3.64:8765/**。网站已运行时不会重复启动；此命令不会让机器人移动或播报。

## 2. 跟着网页走

| 场景 | 用户操作 |
| --- | --- |
| 已有地图、换电重启 | 一键初始化 → 必要时点选大致位置/朝向 → 对照现场核对绿色箭头 |
| 添加展点 | 遥控到展点并调好朝向 → 停稳 → 添加导览点 → 上传/核对展板资料 → 读取位置并保存 |
| 前往展点 | 点位导航 → 选择登记点 → 确认落地、官方运动模式、拆绳、停稳和监护 → 预览/PIN 确认 |
| 停止 | 网页停止全部任务；紧急情况用官方遥控器/物理急停 |

点位移动不依赖示教路线，也不触发 Omni 或讲解。当前速度上限 .60 m/s、.70 rad/s，避障和接近终点会减速；到达/失败后禁用运动。

## 3. 新场地的建图入口：尚需补齐

目标交互是 **开始建图 → 遥控走一圈 → 结束并保存 → 自动准备地图 → 登记展点**。目前建图/保存脚本存在，但网站尚未实现完整建图生命周期、地图一致性验收和版本切换，因此不能声称“新场地网页一键复现”已完成。不要用导航初始化代替建图。

完整产品化验收清单见 [复现契约](REPRODUCIBILITY.md)；当前现场部署见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 可复现性说明

当前可以固定 Git 源码版本并重复运行隔离测试；不是包含 ROS/SDK、现场地图/点位、密钥和硬件验收的一键镜像。仅 500 项软件测试通过，不能证明全场路线和新硬件环境无需调试。用户不应承担 TF/消息/构建排错；这些应由下一阶段自动环境准备和网页诊断收敛。

SSH 转发、API 预览/模拟、新 PC2 部署细节：[开发者 Quickstart](QUICKSTART_API.md)。如果你只操作机器人，不必阅读或执行其中 API 命令。
