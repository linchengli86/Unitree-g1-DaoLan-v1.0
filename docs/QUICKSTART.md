# Quickstart · 一个入口，从网页开始

> 此流程说明技术部署，不代表全部组件的使用或再分发授权已核实。公开分发和社区复用前须完成 [许可检查表](THIRD_PARTY.md)；当前候选版尚未通过许可审查。

适用：Unitree G1，Ubuntu 20.04 / aarch64 PC2，内部 eth0 与 MID360 已接通，可信 ROS Noetic apt 源已配置。此版是网页建图候选版：软件回归通过，尚待干净 PC2 安装和新场地全流程实机验收。原有现场导航基线保留。

## 1. PC2 首次准备一次

将仓库克隆到 PC2 的 `~/robot/DaoLan`（不要覆盖已部署目录），SSH 进入 PC2 后执行：

```bash
cd ~/robot/DaoLan
bash scripts/quickstart.sh --prepare
```

会请求 sudo，安装依赖、构建 SDK/ROS 工作空间并启动网站；不建图、不定位、不行走。已有配置和地图不会被此命令覆盖。默认纯运动，不需要模型 Key、语音或麦克风；安装失败不会继续启动任务。[部署前提](DEPLOYMENT.md)

## 2. 浏览器跟着“首次设置”走

打开 **`http://<PC2-IP>:8765/setup`**（当前现场常用 `192.168.3.64`）。

| 场景 | 网页操作 |
| --- | --- |
| 新场地，无地图 | 开始新建图 → 遥控走遍场地 → 停稳、结束并保存 → 预览核对 → 备份旧图并激活 |
| 已有地图 | 跳过建图；一键初始化 → 必要时点选大致位置/朝向 → 对照现场核对绿色箭头 |
| 添加展点 | 遥控到展点并调好朝向 → 停稳 → 添加导览点 → 上传/核对展板资料 → 读取位置并保存 |
| 首次开放网页导航 | 在首次设置中设 PIN；仅在兼容环境和导航模块已验收后，明确确认开放点位导航 |
| 前往展点 | 点位导航 → 选登记点 → 确认落地、官方运动模式、拆绳、停稳和监护 → 预览/PIN 确认 |

建图只由你遥控。新图审核前不替换旧图；激活新图会归档旧点位登记，照片/文献保留，需重新登记新图点位。移动不依赖示教路线，不触发 Omni/讲解；速度上限 .60 m/s、.70 rad/s，避障和接近终点会减速，到达/失败后禁用运动。

## 3. 以后开机只需启动 + 初始化

```bash
cd ~/robot/DaoLan
bash scripts/quickstart.sh
```

打开网页 → 初始化/核对定位 → 选点前往。不重复安装、不重复建图。只读环境检查：`bash scripts/quickstart.sh --check`。

停止用网页“停止全部任务”；紧急情况用官方遥控器/物理急停。建图取消/保存时等状态退出后再换电。网页不能给硬件通电、切官方运动模式或确认现场安全。
